# Interactive_Campus_Map
Our (attempted) approach at making a campus app, capstone project

# How to edit website
Whenever the code is changed and pushed, firebase automatically pushes the changes to the website and domain.
https://emumap-c36a9.web.app/ <- this is the link to the live domain.

# Important
When updating the website, make sure you npm run dev from the frontend_map directory and test locally first.

# ArcGIS
ArcGIS updates in real time. Whenever a change is made to the map, the domain will automatically update with the changes.

# Directions
Make sure Node.js is installed and make sure firebase is installed. If errors remain, continue to install dependencies until it works properly to run it locally.
